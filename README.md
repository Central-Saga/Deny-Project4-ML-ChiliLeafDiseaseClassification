
# Chili Leaf Disease Classification

Machine Learning-based chili leaf disease classification integrated with an Android application using Kotlin.

## Project Overview

This project aims to classify chili leaf diseases using Deep Learning and image classification.

The model will be trained using Python and TensorFlow, then integrated into an Android application for offline image classification.

## Technologies

- Python
- TensorFlow / Keras
- Google Colab
- TensorFlow Lite
- Kotlin
- Android Studio

## Project Structure

- `ml/notebooks/` - Model training and experiments
- `ml/models/` - Trained Machine Learning models
- `ml/results/` - Evaluation results and graphs
- `android-app/` - Android Kotlin application
- `docs/` - Project documentation
